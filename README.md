### Ciência, tecnologia e aplicações no cotidiano

## Sobre o projeto

O **Radiação Infravermelha** é um projeto educacional desenvolvido com o objetivo de apresentar, de maneira interativa e informativa, os principais conceitos relacionados à radiação infravermelha.

Por meio de uma interface digital, o projeto explora desde o contexto histórico de sua descoberta até suas propriedades físicas e aplicações na sociedade contemporânea, especialmente nas áreas de tecnologia e saúde.

A proposta é tornar o conhecimento científico mais acessível, reunindo informações relevantes em uma plataforma visualmente organizada e de fácil navegação.

## Conteúdo do site

O site está organizado em seções temáticas:

| Seção | Descrição |
|---|---|
| História | Contexto histórico da descoberta da radiação infravermelha. |
| Cientista | Biografia e contribuições de William Herschel. |
| Características físicas | Comprimento de onda, frequência e radiação térmica. |
| Aplicações tecnológicas | Termografia, controles remotos, astronomia e sensores. |
| Saúde | Utilização da radiação infravermelha em equipamentos e procedimentos da área da saúde. |
| Orientador | Apresentação do professor responsável pelo projeto. |

## Funcionalidades

- Navegação entre as diferentes seções do conteúdo.
- Calculadora interativa para explorar a relação entre frequência e comprimento de onda.
- Apresentação de informações científicas por meio de elementos visuais.
- Galeria de imagens relacionadas ao desenvolvimento do projeto.
- Organização responsiva da interface para diferentes tamanhos de tela.

## Como executar o projeto

Para visualizar o site em seu computador:

1. Faça o download ou clone este repositório.
2. Abra a pasta do projeto no Visual Studio Code.
3. Localize o arquivo `index.html`.
4. Abra o arquivo em seu navegador para visualizar a página.

Também é possível utilizar a extensão Live Server no Visual Studio Code para facilitar a visualização durante o desenvolvimento.

## Objetivo educacional

Além da apresentação dos conceitos físicos, o projeto busca demonstrar como conhecimentos científicos podem ser aplicados em situações reais, evidenciando a importância da radiação infravermelha em diferentes campos da ciência e da tecnologia.

O desenvolvimento também proporciona a aplicação prática de conhecimentos relacionados à programação e ao desenvolvimento web.
